### 🚀 Featured projects

**[IDS-Blockchain](https://github.com/waliddoesthis/Ids-Blockchain)** — Real-time network intrusion detection · 🥇 1st place, ENSAM project competition 2026
A CNN-BiLSTM + multi-head attention flow classifier trained on **16.2M flows** (CSE-CIC-IDS2018) scores live traffic, and high-severity alerts are hashed into a private MultiChain ledger so the alert history can't be quietly rewritten. My part: preprocessing, model training, evaluation and the inference API. **Macro-F1 0.77 over 15 classes, 91.6% accuracy, 98.6% benign recall.**
`PyTorch` `Spark` `Kafka` `MultiChain` `Streamlit` `Docker Compose`

**[EcoRoute](https://github.com/waliddoesthis/ecoroute)** — Security-aware LLM router
An LLM gateway that sends each request to the cheapest model likely to answer it correctly, but only among models cleared for the prompt's data sensitivity (PII detection + clearance filter). **−69.7% cost vs always using GPT-4o, within 0.3 points of accuracy, 74 ms median decision.**
`Python` `PyTorch` `Graph model` `PII detection` `OpenAI-compatible API`

**📡 LoRaWAN security research** — *current main quest*
Writing a research paper on the security of LoRaWAN, the long-range radio protocol behind millions of IoT devices. Findings stay classified until publication.

**Serverless SIEM + ML on AWS** — Wazuh alerts ingested, enriched and scored by a model inside AWS Lambda, stored on S3, with a Streamlit console on EC2.
`Wazuh` `AWS Lambda` `S3` `EC2` `Scikit-learn`
